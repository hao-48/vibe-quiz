# Design

## Context

目前專案尚無既有應用程式、資料模型或 Guided Notes 範本。動機見 [proposal.md](proposal.md)，對外行為見 [classroom-quiz 規格](specs/classroom-quiz/spec.md)。以下的標記語法、同步方式與儲存選擇為首版設計。

## Goals / Non-Goals

**Goals**

- 為回合切換和作答建立可重現的事件順序。
- 讓題目與填空格的對應可預覽、遇到衝突時可追查，並支援重新定位與安全重試。

**Non-Goals**

- 不提供跨裝置部署、跨活動隔離或多人同時管理同一份來源。
- 不保證本機服務程序重啟後可還原教學活動。頁面重整與 Sheets 暫時斷線期間可繼續使用服務內已載入的活動。

## Decisions

### 技術選型

- Python 標準函式庫提供僅限迴路介面的 HTTP 服務，以 SSE 推送角色專屬狀態，並以 JSON 請求處理操作。離線展示與測試可直接執行，無須安裝套件。
- 前端使用 HTML、CSS 與原生 JavaScript，由本機服務直接提供，同一瀏覽器可開啟老師與 A/B 組視窗。
- Google Sheets 模式選用 google-api-python-client 與 Google Application Default Credentials。離線模式載入兩份合成工作表，透過同一套定位及預檢流程在記憶體寫回。

### 本機服務掌握狀態與角色

服務僅監聽本機介面，以老師、學生組別各自的工作階段維護角色。老師入口透過本機啟動流程取得角色，學生入口只取得所屬組別身分。服務端驗證操作權限；僅用頁面名稱或查詢參數指定角色，會讓學生直接呼叫老師操作。

老師與學生各自開啟頁面。服務接受操作請求並推送角色可見的狀態；重整或重連先取得目前快照。事件順序由服務端集中管理，避免使用各瀏覽器的時鐘或各自保存階段。首版可使用記憶體保存題單、回合與結果。

### 在同一事件序列處理作答與結束

每次開題對應一個回合識別值。接受作答時驗證組別、回合、階段及答案，然後在同一不可分割的狀態更新中分配收件序位、存下答案並決定是否鎖定勝者。結束事件使用同一序列。以組別、回合及提交識別值辨識重送，回傳原回執；同一識別值帶不同內容視為衝突。切換題目時拒絕舊回合請求。

同步與重連快照分角色產生。結束前，學生的個別回執不觸發公開的作答進度或勝負更新。結束後學生取得勝出結果，老師可查閱所有已接受答案。

### 題目鍵與填空佔位符分開保存

首版範本約定在題目清單各列若干儲存格中放置獨立文字標記 `{{Q:題目鍵}}`，填空格左側相鄰的獨立儲存格使用 `{{A:題目鍵}}`。題目清單依題目標記所在列排序，每列一題。顯示題號可直接使用題目鍵。匯入掃描老師指定的工作表，依鍵驗證一對一，並將來源試算表與工作表的穩定識別值與題目鍵一起保存。每個填空格須是單一可寫入儲存格，且不能與題目或標記重疊。

以題目鍵及相對位置重新計算目標格。獨立標記在寫答案後仍保留，可支援移列與重試。曾考慮把佔位符直接放在答案格，第一次寫回即會替換它，後續便無法用同一契約重新定位。

### 批次寫回前重新檢查並讀回確認

每次寫回依保存的來源識別值重新讀取題單與佔位符。以匯入的題目鍵集合核對來源，再重新定位每個已結束且有勝者的填空格。空白格可寫，已有完全相同的純文字視為完成；不同的文字、公式、保護或模糊對應均為衝突。任一衝突出現時，列出受影響題目並停止送出整批寫回。

預檢通過後，將仍待寫的目標格集中送出，要求試算表以純文字儲存，避免答案被解讀為公式。重複觸發的寫回在本機服務內依序處理。遠端回覆中斷時記錄為待確認，重新讀回後才可重試。逐格寫回會增加部分成功的機會，因此以可整批處理的寫入方式為設計目標。

### 由服務端取得執行環境的授權

服務端以執行期授權存取指定試算表，採最小必要權限。憑證不進入前端、repo、文件、測試資料或日誌。避免在 repo 管理持久金鑰檔，測試使用合成題單和答案。介面與驗收文字使用繁體中文，規格保留 OpenSpec 的英文結構標題及規範關鍵字。

## Risks / Trade-offs

- 範本缺少相容標記 → 匯入時列出題目鍵或標記位置。用兩份不同位置及題數的合成 Guided Notes 驗證契約。
- 預檢後仍可能有外部協作者或自動程序同時編輯 → 展示時使用專用試算表並避免並行修改。批次預檢無法保證跨 Sheets 讀寫的交易隔離，寫回後讀回核對並呈現異常。
- Sheets 斷線或授權失效 → 保持本機活動可用，保留結果供恢復連線後重試。
- 本機多角色操作以教室展示為前提 → 透過角色工作階段及服務端檢查隔離畫面與請求，同一台電腦的操作者仍可切換已開啟的老師視窗。

## Migration Plan

專案目前無舊資料或介面需遷移。首次部署以兩份合成範本驗證。既有 Guided Notes 若無標記，須先依範本契約加入標記。停止本機服務即可停用功能，已寫回的答案可透過試算表版本紀錄處理。
