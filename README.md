# vibe-quiz 課堂搶答系統

同一台電腦可開啟老師、A 組與 B 組頁面。第一筆有效答案由本機服務依收件順序判定勝出。老師結束當題後，各頁面即時揭曉。

## 離線啟動與操作

需要 Python 3.10 或更新版本，以及支援 SSE 的現代瀏覽器。離線模式僅需 Python 標準函式庫。

```powershell
python app.py
```

1. 服務會開啟老師頁。若 8000 埠已被占用，可執行 `python app.py --port 8001`。
2. 在老師頁選擇範本一或範本二，按「匯入題單」，核對題數、題序及填空格。
3. 用老師頁的「開啟學生入口」兩次，在兩個新分頁分別加入 A 組和 B 組。也可在兩個獨立視窗開啟終端顯示的學生網址。
4. 老師按「開始搶答」。每組可送出一筆有效答案。老師按「結束並揭曉」後，各頁面顯示勝出者與答案，老師另可查看各組答案。按「下一題」回到等待中。
5. 按「寫回 Guided Notes」並確認。離線模式只更新本次執行中的合成工作表，兩份 JSON 原檔保持不變。再次寫回相同結果時，已存在的答案會略過。

用 Ctrl+C 停止服務。重新啟動會開啟新的老師頁與活動，舊頁面的工作階段會失效。

## Google Sheets 模式

在 Google Cloud 專案啟用 Google Sheets API，透過本機執行環境設定具 Sheets 存取權限的 Application Default Credentials（ADC）。執行身分須能讀取及編輯目標試算表。憑證檔若由環境管理，放在 repo 之外，請勿將真實憑證或課堂機敏資料放入工作區或測試資料。

```powershell
python -m pip install -r requirements-google.txt
python app.py --mode google
```

老師頁輸入 Google 試算表網址或 ID，以及工作表分頁名稱。寫回會更新匯入時指定的原工作表。操作期間請避免協作者同時修改範本，以免變更落在預檢與實際寫回之間。

## Guided Notes 範本

- 題目清單每列放一個獨立文字標記，例如 `{{Q:甲}}`。題目依標記所在列排序。鍵值不可重複，須為不含空白或大括號的文字。畫面可只顯示題號。
- 在答案格左側的獨立儲存格放置相同鍵值的填空佔位符，例如 `{{A:甲}}`。該標記右邊第一格為答案格，必須在同一工作表內，且不可與其他標記重疊、合併或受保護。
- 例如，新建一份測試工作表，在兩個不同列的任意欄放置 `{{Q:單元二}}` 與 `{{Q:單元一}}`，再於其他位置各放 `{{A:單元一}}` 與 `{{A:單元二}}`，右邊各留一格。若「單元二」的題目標記在較上方，預覽就先顯示「單元二」。
- 在活動中移動填空位置時，請將佔位符與右側填空格一起移動。寫回前會重新依標記定位。不同內容、公式、無效格位或不唯一的對應會阻止整批寫入，請依頁面提示修正後重試。

## 測試

```powershell
python -m unittest discover -s tests -v
```

測試使用合成資料，涵蓋角色權限、收件順序、即時同步、兩份範本的完整流程、衝突處理與讀回重試。整合測試需可連線至本機迴路介面。Google Sheets 請求與錯誤處理以模擬服務驗證。
